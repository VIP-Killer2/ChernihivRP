KYIV RP — перші файли

ЩО Є В АРХІВІ
1. index.html — структура сторінки: заголовки, кнопки, форма та фракції.
2. style.css — зовнішній вигляд: зелений анімований фон, картки, кнопки та адаптація під телефон.
3. app.js — невелика перевірка полів форми. Поки що вона НЕ створює справжній акаунт.
4. README.txt — ця інструкція.

ЯК ПЕРЕГЛЯНУТИ
- Розпакуй ZIP-архів.
- Відкрий папку kyiv_rp_first_files.
- Відкрий index.html у браузері (Chrome тощо).

ВАЖЛИВО ПРО БЕЗПЕКУ
- Не публікуй пароль ADMIN12 у коді сайту.
- Ці файли — лише перший візуальний прототип.
- Справжня реєстрація, унікальні ніки, захищені паролі, ролі власника/адмінів та підтвердження власника поштою потребують підключення серверної частини й бази даних (наприклад, Supabase).
- Не вводь тут справжній пароль: форма демонстраційна.
